# FocusFlow — ApexPlanet Internship Task 5

A simple productivity dashboard built using **HTML, CSS and vanilla JavaScript**.

## Features
- Add, complete and delete tasks
- Priority levels
- All / Pending / Completed filters
- LocalStorage persistence
- Dark mode
- Responsive desktop, tablet and mobile layout
- Lightweight local SVG asset
- Semantic HTML and accessible labels
- CSS media queries and reduced-motion support

## Performance / Optimization
- No external libraries or frameworks
- No unnecessary network requests
- JavaScript loaded with `defer`
- Local SVG asset instead of a large raster image
- Lazy loading enabled for the illustration
- Minimal CSS/JS structure
- Responsive breakpoints for different devices

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.
